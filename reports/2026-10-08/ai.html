Anthropic 发布 Claude Haiku 5.5，运行成本平均降低约 75%✅ 结构化源

Anthropic：Newsroom（网页）2026-10-07（官方页面日期；API 原始时间为10月6日） · 收录 10-08 02:21模型发布/更新
Anthropic 发布 Claude Haiku 5.5，定位为迄今最便宜、最快的小模型，适合摘要、压缩、数据库查询、分类等高吞吐任务，并可搭配 Opus 5.5 和 Sonnet 5.5 担任编码子智能体。
▾

深度解读

Anthropic 官方页面标注10月7日发布 Claude Haiku 5.5，定位高吞吐、成本敏感任务，包括摘要、压缩、数据库查询和分类，也可作为编码子智能体。公司称平均运行成本较 Haiku 4.5 降低约75%；这是其披露口径，不能视作每个工作负载的固定节省比例。

官方价格表按提示长度分档：不超过10万 token 时，每百万输入为0.10美元、输出0.50美元；超过该长度时分别为0.50美元和2.50美元。本代首次为 Haiku 提供可调 effort，同时降低 Sonnet 5.5 缓存读取价格，并引入 Max 与 Team 月度 API 额度。

💭 分析：短输入、高频调用最值得重新测算成本，但长输入分档、缓存比例和推理 effort 都会影响账单。官方基准展示了能力变化；具体业务的准确率和延迟仍需用自己的任务验证，不能只按价格替换模型。

来源：Anthropic：Newsroom（网页）

Liquid AI 发布开源决策模型 d1-3B 和 d1-omni-600M✅ 结构化源

Liquid AI 模型与工程博客（网页）2026-10-07 08:00 北京时间 · 收录 10-08 01:05模型发布/更新
Liquid AI 发布开源权重决策模型 d1-3B 和 d1-omni-600M，已在 Hugging Face 上提供。
▾

深度解读

Liquid AI 于10月7日公开 d1-3B 与 d1-omni-600M 权重。决策模型以一次前向计算产生答案，不逐 token 生成文本。d1-3B 接收文本和图像，d1-omni-600M 则可处理文本配图像或文本配音频；后者被明确描述为实验性检查点。

公司给出公开 Decision Index 上的测试及不同设备的端到端延迟：d1-3B 在 RTX 4090 单问题测试为8毫秒，在 Jetson Orin Nano 为50毫秒。原文还分别测试长状态和图像输入，延迟显著不同，因此短问题结果不代表所有请求。

💭 分析：直接输出决策适合选项明确的任务，开放权重便于本地评估。多模态能力的证据仍有边界：此次未报告私有视觉分项，专用音频决策基准也仍待建立；部署前应补测真实输入长度和误判成本。

来源：Liquid AI 模型与工程博客（网页）

Google Developers Blog（RSS）2026-10-07 08:00 北京时间 · 收录 10-08 03:44产品发布/更新

▾

深度解读

Google 于10月7日介绍 Developer Knowledge API 生态，为 Google Cloud、Firebase、Android 等官方开发文档提供程序化访问。接口输出 Markdown，支持语义与关键词搜索、分块检索及基于文档的问答；官方称索引频繁更新，但没有在文中承诺固定实时延迟。

LangChain 重构 Deep Agents 的 Skills 支持，新增工具绑定、固定技能与线程内重载✅ 结构化源

LangChain：Blog（RSS）2026-10-08 02:49 北京时间 · 收录 10-08 03:22产品发布/更新
LangChain 重构 Deep Agents 的 Skills 支持，针对企业技能库增至数千个技能的场景推出三项更新：工具可绑定到技能、仅在该技能被读取时加载，用户可通过 /meeting-prep 之类的显式请求固定技能以在首次模型调用前加载，长线程可通过将 skills_metadata 设为 None 重载新增或变更的技能。
▾

深度解读

LangChain 于10月7日介绍 Deep Agents 的三项技能更新：把工具绑定到技能、运行时固定技能，以及在线程中重载技能。企业技能库增长是文章讨论的背景；普通机制仍先暴露名称与描述，再按需读取完整指令与资源。

绑定工具后，模型读取技能才获得对应工具。对支持对话中追加工具的新模型，工具信息可加入后续消息并保留此前提示缓存；其他模型仍追加到请求工具列表。固定技能可在首次调用前加载用户指定的指令，重载则让长线程获取技能变更。

💭 分析：这些功能减少技能与工具分散发现的步骤，但缓存保留依赖具体模型的支持。运行时权限筛选工具可作为访问控制的一部分；是否减少成本和漏加载仍需在实际技能库与调用轨迹中验证。

来源：LangChain：Blog（RSS）
