阿里发布 Page Agent: 开源 JS 库实现网页 DOM 自然语言操控

MarkTechPost · 7月3日
▼

阿里巴巴正式开源 Page Agent，这是一个轻量级 JavaScript 库，允许开发者通过自然语言指令直接操控网页 DOM 元素。与传统自动化框架（如 Puppeteer、Playwright）依赖 CSS 选择器或 XPath 不同，Page Agent 利用嵌入的小型语言模型在浏览器端实时解析用户意图，将"点击登录按钮""填写表单中邮箱字段"等自然语言指令映射为 DOM 操作。核心优势在于零配置、低延迟（完全在浏览器内运行，无需服务器往返）和对动态渲染页面的良好适应性。该库特别适合构建 AI 辅助的浏览器自动化、无代码网页操作工具以及智能体与网页交互的中间层。阿里此举将"AI + 浏览器"的门槛大幅降低，让前端开发者无需深度学习即可赋予网页 AI 操控能力。
