Sand.ai 的 MAGI-2 登陆 Higgsfield，最长生成 30 秒视频

Higgsfield11月25日 05:49模型发布/更新
平台开放网页和 API 两种入口，按生成时长计费。
▾

事实与分析

Higgsfield 上线 Sand.ai 的视频生成模型 MAGI-2。官方目录将其列为独家模型，文字生成入口可输出 1080p 视频，时长可选四至三十秒，提供六种宽高比，并允许选择是否生成音频。用户可以在提示词中描述画面和运动，再由接口按所选时长与画幅生成片段。目录给出的起价为每秒 0.08 美元。

Higgsfield 同时在 Video Arena 公布了这款模型的盲测结果，官方帖称其当时列第二，整体胜率为 60.5%。这个数字对应平台自己的对比测试，适合与该榜单的其他结果一同阅读。平台把可调用的商用入口和未来的开放权重计划分别说明。现阶段要试用可以走 Higgsfield 网页或 API，开放权重则仍属于预告。对于需要比较素材生产成本的团队，可以先固定时长和画幅，在同一任务上记录各生成方案需要重试几次，再把重试计入实际成本。

Cognition 发布 SWE-2.1 及高速推理版本

Cognition11月25日 03:07模型发布/更新
新版沿用 Kimi K3 基座，Devin 同时提供常规与高速入口。
▾

事实与分析

Cognition 发布编码模型 SWE-2.1。它和 SWE-2 一样，以 Kimi K3 为基座做纯强化学习。团队扩大了训练任务与环境的范围，同时纳入短周期操作和需要持续多步执行的工作。公司把通用推理和长流程任务上的训练改动，列为新版编码能力改善的主要来源。

在官方报告的 Terminal-Bench 4.1 中，SWE-2.1 的得分为 50.0，SWE-2 为 24.2。公告也列出了 FrontierCode 2.0 等基准。在 Devin 内，公司同步提供 SWE-2.1 Lightning，使用 Cerebras 的推理服务加快同一模型的输出，并向 Devin Pro、Max 和 Teams 用户提供两周的免费使用窗口。

选型时可以分别记录模型在一个既有仓库里完成任务的比例，以及从发出请求到验证通过的总时间。高速版本缩短的是推理等待，完整任务还要计入工具执行、测试和人工验收，因此这两项数据能帮助解释一次实际升级的收益。

Midjourney 发布面向动漫创作的 Niji V8

Midjourney · ORIENS11月25日 04:37模型发布/更新
发布帖将指令遵循、角色一致性和独立编辑模型列为主要更新。
▾

事实与分析

Midjourney 于当地 11 月 24 日在官方账号宣布 Niji V8 上线，北京时间为 11 月 25 日。Niji 是其面向动漫和插画风格的模型系列。此次公告突出精细提示词控制、角色一致性、画面连贯性，以及一个专门用于编辑的模型。日本媒体 ORIENS 随后核对了该帖，并记录发布消息中暂未给出性能对比数字、收费或具体套餐条件。

这几项更新对应创作流程里的不同工作。精细提示词控制关系到一张图是否呈现创作者指定的构图与细节，角色一致性则适用于同一角色反复出现在不同镜头。独立编辑模型面向已有图像的修改，和用文字生成首张图是两个环节。

目前可以按照公告列出的能力做验收。例如，在相同图像比例下让同一角色出现在数个镜头，再逐项核对外观特征与动作描述。这样能把单张图是否好看和一组图能否连续使用分开记录。

来源：https://ai-oriens.com/news/midjourney-niji-v8/ https://x.com/midjourney/status/2125328040624521639

字节 Seed TTS 3.0 在 fal 提供多语种语音合成

fal11月25日 02:22模型发布/更新
接口支持自然语言表达指令，并提供语速、音调和音量参数。
▾

事实与分析

fal 上线字节跳动的 Seed TTS 3.0。官方模型页将它列为从文本合成语音的端点，输入包括要朗读的文本，也可以选择音色，用自然语言描述希望采用的表达方式，并调节语速、音调和音量。fal 的发布材料介绍了超过一百种语言及其变体，演示则用英文对比了低声叙述与高强度喊话等表现。

这一接口把朗读内容、表演要求和声音参数留在同一个工作流程里。试用时可以先保持文本和音色一致，只调整表达描述，观察重音和停顿是否符合预期。再保持表达指令一致，逐一改变语速、音调或音量，确认应用能否用参数复现所需效果。

对多语言内容，英文示范主要说明 fal 所演示的表达范围。实际接入可以用目标语言的产品名、人物名和数字逐段检验，并以对应语种的试听记录来判断配音是否满足交付要求。

事实与分析

API 先通过百度千帆提供。这次发布的新增信息在于开发者可直接取得预览版权重，随后可以在自己的运行环境里检查长上下文、依赖工具以及部署资源的实际表现。

Claude Artifacts 开始支持安装为桌面应用

Anthropic11月25日 04:42产品发布/更新
Mac 和 Windows 客户端进入公测，可将常用产物放到独立窗口。
▾

事实与分析

Anthropic 在 Mac 和 Windows 版 Claude 中推出公测功能，允许用户把 Artifact 安装成有独立窗口和图标的桌面应用。用户可以先在 Claude 对话里描述需求和试用产物，再选择安装。底层 Artifact 被修改后，桌面应用会同步更新，也可以把应用分享给别人。

对每天都要打开同一面板的用户，这项更新省去了先找到旧对话，再打开产物的步骤。使用时可以把应用窗口、关联的数据连接和可用权限逐项核对。共享前也可以检查底层产物在后续修改时会改变哪些内容，以便明确接收者拿到的版本。

Google Workspace MCP 服务器与官方 CLI 正式可用

Google Workspace11月25日 02:32产品发布/更新
个人模式简化 OAuth 设置，组织则获得更细的管理选项。
▾

事实与分析

Google 宣布 Workspace 的 MCP 服务器和官方命令行工具正式可用，并公布标准化使用层级。支持的服务覆盖 Gmail、Drive、Docs、Sheets、Slides、Calendar、Chat 和 Tasks。开发者可以用兼容的客户端连接远端 MCP 服务器，或者通过 Workspace CLI 在命令行中操作相应服务。

个人模式的改动是可以在 Google Cloud 控制台快速建立只供自己 Google 账号使用的 OAuth 客户端。配置指南按网页应用和桌面或移动端的授权流程分别给出入口。个人模式省去了独立配置 OAuth 同意屏幕和提交应用验证的步骤，开发者仍然需要选择或建立自己的云项目。

对企业，公告同时列出 Workspace AI Tools 附加协议与扩展管理控制。试用可以从单一账号和少量服务开始，随后由管理员核对组织权限、授权范围和用量层级，再决定要把哪些工作流程交给已授权的客户端。

来源：https://workspaceupdates.googleblog.com/2026/11/ https://developers.google.com/workspace/guides/configure-mcp-servers?hl=en

Baseten 用短期只读凭证部署 Hugging Face 私有模型

Baseten11月25日 03:27产品发布/更新
Hugging Face 校验部署身份后，发放限定仓库的访问令牌。
▾

事实与分析

Baseten 宣布支持 Hugging Face 的只读 Trusted Publishers。团队部署保存在私有仓库的模型时，可以把授权绑定到部署工作负载。Baseten 会在部署阶段提供 OIDC 身份令牌，Hugging Face 校验签名，并按可信发布者配置核对组织、团队和工作负载类型。

校验通过后，Hugging Face 发放只允许读取单个仓库的一小时令牌。部署程序随后可以拉取私有权重，但这份令牌本身不带仓库写权限。Baseten 表示它是首家支持这种只读方式的推理服务提供商。公司此前也为从 S3 和 Google Cloud Storage 拉取权重提供基于 OIDC 的方案。

这个变化把部署需要的读权限与团队日常使用的账号凭证分开。接入时可以分别检查仓库绑定、部署工作负载的标识，以及期望能下载的版本。遇到权限问题时，这些字段也能帮助定位是身份匹配还是仓库授权环节出了问题。

来源：https://www.baseten.co/blog/deploy-private-hugging-face-models-without-sharing-your-access-token/
